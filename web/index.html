格式与时间字段

scans.csv
scan_id,ts,picker,location,task,device,source,kind,duplicate_of,note
S00001,2026-11-11T08:00:39+00:00,P01,B3-L03,D1-001,HH-101,handheld,pick,,
  • kind：pick / confirm / repeat / manual。repeat 会被合并进上一次扫描，并保留审计记录。
  • duplicate_of：重复扫码指向原始 scan_id；缺失时按同人同货位短间隔合并。
  • cancelled_at：任务取消时间。取消前取消的任务不产生扫码；取货中途取消的任务保留已发生的扫码。
  • 旧货位条码在拓扑的 aliases 中映射到当前货位，改版前的历史事件仍按当时区域解释。
